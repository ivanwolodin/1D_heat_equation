# 1D Heat Equation

Numerical implementations of finite difference schemes for solving the one-dimensional heat equation.

## Implemented Methods

- **Explicit scheme** — an explicit finite difference method.
- **Implicit scheme** — an implicit finite difference method.
- **Thomas algorithm** — a tridiagonal matrix algorithm used for solving systems of linear equations.

## Project Structure

```text
.
├── 1d_heat_equation.pdf  # Problem description
├── explicit_scheme/      # Explicit finite difference method
├── implicit_scheme/     # Implicit finite difference method
└── thomas_algorithm/    # Thomas algorithm implementation
```
